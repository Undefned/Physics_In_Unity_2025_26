# ПОЛНАЯ ТЕОРИЯ ЛАЗЕРА (для сдачи лабораторной)

---

## 1. Что такое лазер?

**Лазер (LASER)** — устройство, генерирующее **когерентный**, **монохроматический** и **направленный** пучок света.

**Акроним:** Light Amplification by Stimulated Emission of Radiation  
(Усиление света с помощью вынужденного излучения)

---

## 2. Три обязательные части лазера

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   НАКАЧКА ─────► АКТИВНАЯ СРЕДА ─────► РЕЗОНАТОР          │
│   (энергия)       (усиление)           (обратная связь)     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

| Часть | Что делает | Пример |
|-------|------------|--------|
| **Накачка** | Передаёт энергию в среду | Газовый разряд, лампа, диод |
| **Активная среда** | Усиливает свет (создаёт инверсию) | He-Ne, CO₂, Рубин, Nd:YAG |
| **Резонатор** | Отражает свет туда-обратно (обратная связь) | Два зеркала |

---

## 3. Энергетические уровни атома

**Уровни** — это разрешённые состояния энергии атома. Атом не может находиться между уровнями (как ступеньки лестницы).

```
E₃ ────────────────── (быстро распадается на E₂)
         ↓
E₂ ─────────► ЛАЗЕРНЫЙ ПЕРЕХОД (излучение)
         ↑
    Накачка (поглощение)
         │
E₁ ────────────────── (основной уровень)
```

| Обозначение | Что значит |
|-------------|------------|
| **E₁** | Нижний уровень (основное состояние) |
| **E₂** | Верхний уровень (возбуждённое состояние) |
| **E₃** | Вспомогательный (быстро падает на E₂) |
| **ΔE = E₂ - E₁** | Разница энергий → определяет цвет лазера |

---

## 4. Откуда берётся фотон?

**Фотон рождается при переходе атома с верхнего уровня на нижний.**

### Два способа:

| | Спонтанное излучение | Вынужденное излучение |
|--|---------------------|----------------------|
| **Причина** | Атом сам, случайно | Прилетел фотон-триггер |
| **Фаза** | Случайная | Такая же, как у триггера |
| **Направление** | Случайное | Такое же, как у триггера |
| **Когерентность** | Нет | Да |

**Формула энергии фотона:**
```
E = h × c / λ
```
где h — постоянная Планка, c — скорость света, λ — длина волны.

---

## 5. Длина волны (цвет лазера)

**Длина волны определяется разницей энергий между уровнями:**

```
λ = h × c / ΔE
```

| Переход | ΔE | λ | Пример |
|---------|----|----|--------|
| Большая разница | Большая | Маленькая (видимый свет) | He-Ne (633 нм) |
| Маленькая разница | Маленькая | Большая (ИК) | CO₂ (10600 нм) |

**Почему у CO₂ λ = 10600 нм?**  
Потому что у CO₂ лазерный переход происходит **между колебательными уровнями молекулы** — разница энергий маленькая. У He-Ne переход **между электронными уровнями атома** — разница большая.

---

## 6. Трёх- и четырёхуровневые схемы

### Трёхуровневая (Рубин)

```
E₂ ─────────► ЛАЗЕРНЫЙ ПЕРЕХОД
         ↑
    Накачка
         │
E₁ ────────────────── (нижний уровень = основной)
```

**Проблема:** Нижний уровень — основной. Атомы скапливаются внизу.  
**Нужно перекачать >50% атомов наверх** → высокий порог.

### Четырёхуровневая (He-Ne, Nd:YAG)

```
E₂ ─────────► ЛАЗЕРНЫЙ ПЕРЕХОД
         ↓
E₁ ────────────────── (быстро распадается)
         ↓
E₀ ────────────────── (основной уровень)
```

**Преимущество:** Нижний лазерный уровень E₁ быстро пустеет.  
**Достаточно нескольких процентов атомов на E₂** → низкий порог.

## 7. Инверсия населённостей

**Инверсия** — состояние, когда **возбуждённых атомов больше, чем невозбуждённых** (N₂ > N₁).

**Без инверсии** — свет поглощается, а не усиливается.

**Формула в модели:**
```
инверсия = мощность_накачки × КПД_накачки × 1.2
```

**Визуализация:**  
- Синие атомы → невозбуждённые (N₁)  
- Жёлтые атомы → возбуждённые (N₂)  
- Количество жёлтых = 20 × (инверсия / 2)

## 8. Накачка

Способ передать энергию в активную среду.

| Тип | Принцип | Для каких сред |
|-----|---------|----------------|
| Газовый разряд | Электроны бомбардируют атомы | He-Ne, CO₂ |
| Ламповая импульсная | Вспышка ксеноновой лампы | Рубин, Nd:YAG |
| Диодная | Полупроводниковый диод | Nd:YAG, GaAs |
| Химическая | Энергия химреакции | CO₂ |
| Другой лазер | Фотоны от другого лазера | Nd:YAG, GaAs |

**Не все накачки совместимы со всеми средами** (матрица совместимости).

## 9. Резонатор

Два зеркала, между которыми стоит активная среда.  
Одно зеркало **полупрозрачное** (через него выходит луч).

### Устойчивость резонатора

Формула g-параметров:
```
g₁ = 1 - L/R₁
g₂ = 1 - L/R₂
Устойчив, если 0 < g₁·g₂ < 1
```

| Тип | R₁ | R₂ | g₁·g₂ | Устойчивость |
|-----|----|----|-------|--------------|
| Плоско-параллельный | ∞ | ∞ | 1 | На грани |
| Концентрический | L | L | 0 | На грани |
| **Конфокальный** | 2L | 2L | 0.25 | **Устойчив** |
| Полусферический | ∞ | L | 0 | Устойчив |
| Кольцевой | — | — | — | Устойчив |

**Зачем нужен резонатор?**  
Без резонатора будет ASE (усиленное спонтанное излучение) — свет во все стороны, нет направленности и когерентности. Резонатор создаёт обратную связь → лавина фотонов → узкий мощный луч.

---

## 10. Расходимость пучка

Угол, на который расширяется луч вдалеке.

**Формула:**
```
θ = 2λ / (π × w₀)
```
где w₀ — радиус перетяжки (самое узкое место луча).

**Чем меньше θ, тем лучше** (луч тоньше, точнее).

---

## 11. Условия генерации (когда лазер работает)

```
ГЕНЕРАЦИЯ = (инверсия > порога) И (резонатор устойчив) И (совместимость)
```

**Если хотя бы одно условие не выполнено → лампочка красная.**

## 12. Ответы на вопросы

### 1. Почему двухуровневая схема не может создать инверсию?

**Ответ:** В двухуровневой системе вероятности поглощения и вынужденного излучения равны. При любой мощности населённости уровней **сравняются** (насыщение), но инверсии (N₂ > N₁) не будет никогда. Это фундаментальное ограничение.

---

### 2. Различие спонтанного и вынужденного излучения. Почему спонтанное — «враг»?

**Различие:**

| | Спонтанное | Вынужденное |
|--|------------|-------------|
| Причина | Случайный распад | Внешний фотон |
| Фаза | Случайная | Когерентная |
| Направление | Случайное | Направленное |

**Почему спонтанное — «враг»?**  
Оно создаёт **некогерентный шум** (фотоны летят во все стороны), который мешает чистой лазерной генерации.  
**Но без него нельзя** — именно спонтанное излучение даёт первый «затравочный» фотон, который запускает лавину вынужденного излучения.

---

### 3. Зачем нужен резонатор, если среда и без него усиливает свет?

**Ответ:** Без резонатора будет **ASE** (Amplified Spontaneous Emission) — свет усиливается, но:
- Летит во все стороны (ненаправленно)
- Некогерентный (разные фазы)
- Низкая интенсивность

Резонатор создаёт **обратную связь** — фотоны многократно проходят через среду, лавина растёт, формируется **узкий когерентный луч**.

---

### 4. Почему у CO₂ λ = 10600 нм, а у He-Ne 633 нм?

**Ответ:** Длина волны определяется разницей энергий между лазерными уровнями: λ = hc/ΔE.

| Лазер | Тип перехода | ΔE | λ |
|-------|--------------|----|----|
| He-Ne | Электронный (между электронными оболочками) | Большая | 633 нм (видимый) |
| CO₂ | Колебательный (между колебаниями молекулы) | Маленькая | 10600 нм (ИК) |

**Что определяет λ активной среды:**  
Только энергетическая структура атомов/молекул среды. Резонатор не меняет λ, он только отбирает нужную моду.

## 13. Похожие вопросы (для тренировки)

| Вопрос | Краткий ответ |
|--------|---------------|
| Что такое инверсия? | Возбуждённых атомов больше, чем невозбуждённых |
| Как зависит порог от схемы? | 3-уровневая → высокий, 4-уровневая → низкий |
| Зачем нужны зеркала? | Для обратной связи |
| Почему рубин не работает при 100%? | 3-уровневая схема, нужно >50% атомов перекачать |
| Что такое расходимость? | Угол расширения луча вдалеке |
| Чем отличается лазер от лампочки? | Когерентностью, направленностью, монохроматичностью |

## Шпаргалка (выучи за 5 минут)

```
ЛАЗЕР = Накачка + Среда + Резонатор

Уровни: E₁ (низ) — E₂ (верх) → λ = hc/ΔE

Инверсия: N₂ > N₁ (жёлтых больше синих)

Вынужденное излучение → когерентность → лавина

Конфокальный резонатор: g₁·g₂ = 0.25 → устойчив

Генерация: инверсия > порога И резонатор устойчив И совместимость
```
